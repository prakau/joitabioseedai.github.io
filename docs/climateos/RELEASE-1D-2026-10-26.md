# Release 1D: a practical market-to-sale workflow

## Scope

Improve the existing JOITAFA Market and Sale Planner, keeping the Vercel host,
CNAME, public website, API keys and farmer record formats intact. Do not invent
live prices, alerts, forecasts, all-India coverage or confirmed buyer offers.

## Farmer-facing changes

- English/Hindi market controls and common Hindi crop/state aliases.
- Up to eight named searches on the current device; apply or remove them.
- Sort real loaded records by date, numeric modal price or mandi. Search the
  loaded subset and limit arrivals to today plus the preceding six calendar days.
- Display prices per quintal or kg. Estimate gross reference value for an entered
  harvest quantity without silently converting invalid/missing amounts to zero.
- Phone price rows show mandi, crop/variety, modal value, date and comparison
  checkbox together. Desktop retains the detailed table. Reduced motion is
  respected; no flashing prices or misleading animated counters.
- Export the filtered view as UTF-8 CSV with feed state, retrieval time, original
  arrival date, original INR/quintal values and validation warning. Escape CSV
  quotes and neutralize spreadsheet formulas in external string values.
- Select 2-5 matching crop/variety records and open Sale Planner with the original
  per-quintal price and converted kg quantity. Review quotes and enter transport,
  fees and commission to compare net proceeds. Do not auto-calculate or auto-save
  a comparison. Feed/mandi/date remain in the buyer labels of saved records.
- When the feed fails, offer real dated cache or the explicit unavailable state,
  official portals and manual quote comparison. Never substitute sample prices.

## Data and safety

Validate/bound feed rows and metadata, drop duplicates and unknown fields, and
screen malformed caches. Preserve publication/retrieval dates rather than replace
them with the current time. Bad prices, unknown/future dates and contradictory
price ranges cannot become a sale handoff or gross estimate.

No record-key/schema migration. Sale comparisons still use
`joita-fa-sale-comparisons-v1`; existing backup versions and IDs are preserved.
The new `joita-fa-market-searches-v1` key contains preferences only (max eight),
not a shared registry or background watcher. These preferences are excluded from
farmer-record backups and the UI says so. The ten-minute sale handoff uses
`joita-fa-market-sale-draft-v1` in sessionStorage, validates selected fields and
amounts, and is consumed once. It does not put private records in a URL.

Backend mandi retries are restricted to known transient transport codes and share
the existing ten-second timeout. TLS validation remains enabled; HTTP auth errors,
throttling, certificate errors and unknown errors are not blindly retried.
Diagnostics expose only a fixed allowlist of network codes, never the upstream
URL, body or credential. No environment, billing or quota settings change.

## Verification

- 85 unit/API/data/stream tests, including arithmetic, dates, mixed-crop rejection,
  expiring handoffs, CSV formula protection, malformed caches and transport errors.
- 58 app browser tests, including the new market-to-sale journey and all existing
  advisory, photo, voice, field records, tools and recovery workflows.
- Seven public-website browser regressions.
- Cold offline first visit/reload of the deferred market module with dated cache;
  existing first-offline 3D, records, saved Hindi advice and cache recovery tests.
- TypeScript/Vite web build and Android-mode bundle/sync.
- Phone (360), tablet (768), desktop (1440) layouts and reduced-motion checks.

Local fixtures establish application behavior, not actual provider uptime or
agronomic/financial accuracy. Check GitHub CI and Vercel on the pushed commit and
verify the production market response and actual Hindi advisory separately.

## Remaining limitations

Data.gov.in returned a connection failure on the public service during the
initial check on 26 October. This update cannot guarantee third-party uptime or
replace a failed feed with real data from an unconnected provider. At most 200
matching records are loaded; numeric ranking is only within that subset and is
not a recommendation to sell at the highest listed value. Confirm crop variety,
grade, current buyer quote and payment terms before travel or sale.

No push notifications, cloud account/sync, price prediction or expert network is
introduced. Values are reference arithmetic, not forecast income, profit or a
guaranteed payment. The existing published Android 1.0.3 test APK is unchanged;
Android-mode compilation does not constitute a new signed/device-tested APK.
The existing deferred Three.js bundle-size warning remains.
